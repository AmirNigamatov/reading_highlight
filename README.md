# Reading Highlights

## Описание

- Это минимальный жизнеспособный продукт (MVP) консольного приложения на Python для хранения и управления цитатами (выжимками) из прочитанных книг. Приложение позволяет добавлять, просматривать и искать цитаты по тексту, источнику или тегам. Данные хранятся локально в JSON-файле. Нет аутентификации — пользователи анонимны.

## Использование

Приложение запускается из командной строки. Перейдите в папку проекта и используйте команды ниже.

### Основные команды

- **Добавление цитаты**:

  python main.py add --text "Ваша цитата здесь" --source "Название книги" --tags "Теги"

- **Просмотр всех цитат**:

  python main.py view

  Если цитат нет: `No highlights yet.`

- **Поиск цитат** (по тексту, источнику или тегам):

  python main.py search --query "слово_для_поиска"

- **Справка**:

  python main.py

### Примечания

- Теги разделяются запятыми (без пробелов после запятых, если не хотите лишних пробелов).
- Данные сохраняются в файл `data.json` в той же папке (создаётся автоматически).
- Если текст содержит специальные символы, используйте кавычки вокруг аргументов.

## Структура файлов

- `main.py`: Основной файл с интерфейсом командной строки (CLI) на основе `argparse`.
- `highlights.py`: Модуль с классом `Highlight` и функциями для работы с данными (загрузка/сохранение JSON).
- `data.json`: Файл с хранимыми цитатами (создаётся при первом добавлении; не редактируйте вручную).
